# 📱 포스트노티 앱 빌드 가이드 (관리자용 / 입주자용)

포스트노티 앱은 하나의 코드베이스로 **관리자용 앱**과 **입주자용 앱**을 선택해서 빌드할 수 있습니다. 
앱을 빌드하거나 안드로이드 스튜디오에서 실행하기 전에 아래 단계를 따라주세요.

---

## ⚙️ 설정 방법 (매우 중요)

`app.config.js` 파일의 맨 윗부분을 확인하세요.

```javascript
// 👇👇👇 주의: 관리자용 앱을 빌드할 때는 아래를 true로, 입주자용 앱을 빌드할 때는 false로 바꾸세요! 👇👇👇
const IS_ADMIN = false;
// 👆👆👆👆👆👆👆👆👆👆👆👆👆👆👆👆👆👆👆👆👆👆👆👆👆👆👆👆👆👆👆👆👆👆👆👆👆👆👆👆👆👆👆
```

### 🧑‍💻 입주자용 앱 (플레이스토어 등록용) 만들기
1. `app.config.js` 파일에서 `const IS_ADMIN = false;` 로 설정하고 저장합니다.
2. 안드로이드 스튜디오에서 **Run** 버튼이나 **Generate Signed APK**를 누릅니다.
3. **결과:** 앱 이름이 `스마트우편알림`으로 설정되며, 실행 시 관리자 로그인 화면이 완전히 숨겨집니다.

### 👑 관리자용 앱 (대표님 및 직원용) 만들기
1. `app.config.js` 파일에서 `const IS_ADMIN = true;` 로 글자를 바꾸고 저장합니다.
2. 안드로이드 스튜디오에서 **Run** 버튼이나 **Generate Signed APK**를 누릅니다.
3. **결과:** 앱 이름이 `포스트노티 관리자`로 설정되며, 실행 시 바로 관리자 로그인 화면이 나타납니다.

---

## ⚠️ 주의사항 (푸시 알림 관련)
- 푸시 알림(Firebase) 충돌 방지를 위해 **두 앱의 패키지명(com.postnoti.app)은 동일하게 유지**됩니다.
- 즉, 하나의 안드로이드 스마트폰에 '입주자용 앱'과 '관리자용 앱'을 **동시에 설치할 수 없습니다.** (서로 덮어씌워짐)
- 관리자(직원)는 본인 폰에 '관리자용 앱'만 설치해서 사용하시면 되고, 일반 입주자는 스토어에서 '입주자용 앱'을 다운받아 사용하면 완벽하게 분리됩니다!
